## 3. 共通の注意

### コード署名警告の説明テンプレ

X / YouTube のリプライで聞かれたら：

```
SmartScreen の「不明な発行元」警告は、コード署名証明書（年1〜数万円）を取得していないために出る挙動です。
SHA256 をリリースページに公開しているので、ダウンロードしたファイルのハッシュと一致するか
PowerShell で `Get-FileHash <file> -Algorithm SHA256` を実行すれば改ざんなしを確認できます。
```

### よくある質問

- **Q: 何が無料？** A: アプリ・公式サーバー・playit.gg 無料枠、すべて無料です
- **Q: PCがついてないと遊べない？** A: はい、ホスト PC が起動している間だけ接続可能です
- **Q: スマホ版マイクラで入れる？** A: はい。サーバー追加でアドレスとポートを入れるだけです
- **Q: アドレスが長くて打ちにくい** A: 一度サーバーリストに登録すれば次回からはタップするだけです
- **Q: アドレスが変わる？** A: playit 無料枠でも、トンネルを残しておけば基本変わりません
