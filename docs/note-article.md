「マイクラ統合版で友達とサーバー立てて遊びたい。でも Realms は課金したくないし、ポート開放とかコマンドとか怖くてよく分からない」

そんな人のために、Windows / Linux 用のデスクトップアプリ **Bedrock Server Manager** を作りました。**完全無料**で、インストール後の数クリックで友達が外部から接続できる状態になります。

## なにを解決するアプリ？

マイクラ統合版で「自宅サーバー」を立てるには、本来こんな手間があります。

- Microsoft の公式 `bedrock_server` を自分でダウンロード・解凍
- `server.properties` をテキストエディタで編集
- ファイアウォール開放
- ルーターのポート開放（やり方は機種によりバラバラ）
- 友達に IP を共有（自宅 IP は変わることがあるし、そもそも教えたくない）
- サーバーの起動・停止はコマンドプロンプトでやる

これを全部 GUI と自動化に置き換えました。具体的には：

- **インストーラから入れて、起動するだけ** で初回セットアップが走る（EULA 同意 → 公式サーバーを自動ダウンロード → デフォルトワールドの準備）
- **「サーバーを起動」ボタン** で起動・停止
- **`server.properties` は GUI フォームで編集**（コメントや並び順は壊れません）
- **playit.gg 内蔵でポート開放不要**。「外部接続を有効にする」をONにすると、`xxxx.ply.gg:12345` のようなアドレスが出ます。これを友達に送るだけ
- **自宅 IP は公開されない**（playit のサーバー経由で中継されるため）

## 主な機能

ダッシュボードで一目で見えるサーバー状態、CPU・メモリのリアルタイムグラフ、稼働時間。それ以外にもざっとこれだけ詰め込みました。

**サーバー管理**
- 起動 / 停止 / 再起動・クラッシュ時の自動再起動
- リアルタイムログ（INFO / WARN / ERROR 色分け・検索・フィルタ・自動スクロール）
- コンソールにコマンド直接送信
- 公式サーバー本体のバージョンチェックと**アップデート**（ワールドデータは保持）

**ワールド**
- 複数ワールドの作成・切替・フォルダを開く
- 既存ワールドの `.mcworld` インポート（スマホ版からエクスポートしたワールドも持ち込めます）
- **サーバー停止時に自動バックアップ**＋手動バックアップ・**ワンクリック復元**（保持世代数も設定可）

**プレイヤー**
- オンライン一覧（右クリックで kick / op）
- ホワイトリスト（`allowlist.json`）
- オペレーター権限（`permissions.json`、visitor / member / operator）
- 一度接続したプレイヤーは「接続履歴から追加」できます

**設定**
- `server.properties` の主要項目はフォーム、その他は raw エディタで
- アドオン（`.mcpack` / `.mcaddon`）の取り込み・有効化トグル
- 曜日 + 時刻で **自動起動 / 自動停止**（毎日21時起動、深夜2時停止、みたいな運用が GUI で設定可能）

**外部接続（playit.gg）**
- シークレットキーを貼って「有効にする」を押すだけ
- 接続アドレスをダッシュボードに大きく表示・コピー
- **「友達への案内文をコピー」** ボタンで定型文を1クリック生成（LINE 等にそのまま貼れる）
- LAN 内のアドレスも併記されるので、家族など同じ Wi-Fi の人はそちらでもOK

## 使い方ダイジェスト

### 1. インストール（Windows）

リリースページからインストーラ `.exe` をダウンロード → 実行。

「Windows によってPCが保護されました」と警告が出たら **「詳細情報」 → 「実行」** で進めてください（コード署名証明書をまだ取得していないため、有名でない exe にはこの表示が出ます。リリースページに **SHA256** を公開しているので、心配な方はそれで照合できます）。

### 2. 初回セットアップ

利用規約・Microsoft EULA に同意 → 「セットアップを開始」を押すと、

- データフォルダ作成
- 公式 `bedrock_server` ダウンロード（約70MB）
- 展開・配置
- デフォルトワールドの用意

が自動で走ります。完了したら Dashboard に着地。

### 3. サーバー起動

サイドバー下の **「▶ サーバーを起動」** をクリック。ログが流れて「起動済み」になればOK。これだけで、同じ Wi-Fi の家族や友達は LAN アドレスから入れます。

### 4. 外部の友達と遊ぶ（playit.gg）

ここが今回のアプリの一番のキモです。

1. [playit.gg](https://playit.gg/) で無料アカウントを作る（メール認証だけ）
2. Agent を作成し、**Bedrock（UDP）トンネル** を `127.0.0.1:19132` 向けに設定
3. playit が発行する**シークレットキー**（64桁の英数字）と、割り当てられた**外部アドレス**（例 `cell-presidential.gl.at.ply.gg:10779`）をアプリに貼って保存
4. **「外部接続を有効にする」** をON
5. **「友達への案内文をコピー」** ボタンを押す
6. クリップボードに次のような定型文が入るので、LINE 等にそのまま貼って送信：

```
Minecraft 統合版サーバーに招待！
サーバーアドレス: cell-presidential.gl.at.ply.gg
ポート: 10779
※「サーバーを追加」で一度登録すれば、次回からはタップするだけで入れます。
```

友達はマイクラ統合版を開いて「サーバーを追加」でこのアドレスとポートを入れるだけ。**ポート開放も自宅 IP の公開も必要ありません**。

## 既知の制約・注意点

正直に書いておきます。

- **PC を起動している間だけ接続できます**。電源を切ると当然サーバーも落ちます（だから自動起動の Windows タスク登録手順を README に書いています）
- **アドレスにはポート番号が付きます**（`yuzu.ply.gg:12345` のような形）。マイクラ統合版は SRV レコードに対応していないので、ポート省略はできません。**ただしサーバー名はマイクラに一度登録すれば次回からはタップだけ**なので、実用上は気にならないはず
- **playit.gg の無料枠**を使っているので、好きな短い名前（例 `yuzu.ply.gg`）にしたい場合は playit Premium が必要。無料のままでも、`二単語-名.gl.at.ply.gg:ポート` の形のアドレスはずっと使えます
- **コード署名証明書を取得していない**ので、Windows SmartScreen の警告が出ます。気になる方は SHA256 で照合してください
- **macOS は今回は未対応**です（次のバージョンで検討）

## なんで作ったの？

これまでの自宅サーバー構築アプリ（似たような物は他にもあります）はだいたい

- 設定がぎこちない（古いUI、英語のみ）
- ポート開放を自分でやれという前提で書かれている
- バックアップやスケジュールが弱い

の組み合わせでした。それを「友達と遊びたいだけの人」が躓かずに使えるところまで持っていきたかったのが動機です。技術スタックは Electron + TypeScript + React + Vite + Tailwind + Zustand。コードは MIT ライセンスで公開しています。フィードバックや機能リクエストはコメント欄か GitHub の Issue に気軽にどうぞ。
